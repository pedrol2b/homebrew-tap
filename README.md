# pedrol2b/homebrew-tap

Homebrew formulae by [@pedrol2b](https://github.com/pedrol2b).

```sh
brew install pedrol2b/tap/lisdex
```

| Formula | What it is |
| --- | --- |
| [`lisdex`](Formula/lisdex.rb) | [Lisdex](https://github.com/pedrol2b/lisdex): menu bar app that keeps your Mac awake. Built from source on install (needs the Xcode Command Line Tools: `xcode-select --install`). |

Formulae here build from source, so the apps are not quarantined and need no Apple Developer ID.
